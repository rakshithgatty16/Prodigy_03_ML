# Cat vs Dog Image Classification

A Machine Learning web application that classifies uploaded images as either a Cat or a Dog using Support Vector Machine (SVM) and Computer Vision techniques.

## Features

* Upload an image for prediction
* Image preview before classification
* Cat vs Dog prediction using Machine Learning
* Clean and responsive user interface
* Flask-based web application

## Technologies Used

* Python
* Flask
* Scikit-learn
* OpenCV
* NumPy
* HTML
* CSS
* JavaScript
